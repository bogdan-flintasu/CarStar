## Tasks
1. **Data model (first commit, multi-tenant ready):**
   - `Organization` (id, name, legal details: legalName, taxId (CUI), regNo, address, phone, email, website; `subdomain`
     unique nullable; `status` 'active'|'suspended'; timestamps), 1:1 `BrandIdentity` (organizationId unique, displayName,
     logoAssetId nullable, primaryColor, secondaryColor nullable, `theme Json` = the `UiTheme`, timestamps), `Asset`
     (id, organizationId, kind 'logo', mime, bytes Bytes, size, width/height nullable, sha256, createdAt).
   - `Configuration` gets `organizationId String?` and `brandingSnapshot Json?` (nullable: old rows have none).
   - Migration with `pnpm prisma migrate dev --name brand_identity` in your worktree. It must also **copy** the existing
     `AppSetting` row `uiTheme` into the default organization's `BrandIdentity.theme` (SQL `INSERT … SELECT` in the
     migration, or an idempotent "ensure default organization" on first read — your choice, document it). Do **not**
     delete the `AppSetting` table or row. One default organization (fixed id, e.g. `default`), created idempotently.
2. **Storage interface** `src/app/api/_lib/assetStore.ts` like `renderStore.ts`: `saveAsset`, `loadAsset`, `deleteAsset`;
   bytes in the DB for now, so S3 can replace it later without touching callers.
3. **`lib/branding.ts`:** keep `getBranding(env)` (env-only, sync, used in tests) and add an async server function
   (e.g. `getActiveBranding()`) that reads the default organization + BrandIdentity from the DB and falls back to the
   environment for anything missing or on a DB error (the configurator must always render). `settings.ts`
   `getUiTheme`/`saveUiTheme` now read/write `BrandIdentity.theme` (fallback: old `AppSetting` row, then default).
4. **Logo upload** in the admin "Interfață" section: PNG, JPG or SVG, at most 1 MB, type checked by **magic bytes**
   (not the extension or the client's MIME); SVG **sanitized server-side** (strip scripts, event handlers, `foreignObject`,
   external `href`s, `<style>` with `url(`; if you cannot do this safely without a new dependency, rasterize-free option:
   reject SVG with a clear message and say so in your report — do not add a dependency without asking; report the need).
   Admin-only route (same auth as other admin routes); public `GET` logo route served with `Cache-Control` and an
   `ETag` (sha256); a versioned URL (`?v=<sha8>`) so a new logo is picked up immediately.
5. **Company name and logo** shown in: the configurator header (`ConfigHeader.tsx`, replace the hard-coded brand),
   the admin header, the PDF quote header, the emails (`emailTemplate.ts`) and the favicon (logo when present, else the
   current `favicon.ico`). Name falls back to `displayName` → organization name → env → default.
6. **"Folosim culorile din logo?"** After an upload, in the browser: draw the logo onto a canvas, extract the 3–5
   dominant colours, skipping near-white, near-black and transparent pixels (pure function `extractPalette(pixels)` in
   `lib/brandColors.ts`, unit-tested with synthetic pixel arrays). Show the swatches, the suggested main and second
   colour, and buttons "Da, aplică" / "Aleg eu" / "Nu, păstrez tema actuală". A one-colour logo gets a neutral second colour.
7. **Theme generator** `lib/themeGenerator.ts`: from 1–2 brand colours produce three `UiTheme` variants "Luminos",
   "Întunecat", "Bară în culoarea firmei" (the price bar filled with the brand colour, buttons in a darker shade of it).
   Every text/background pair must meet WCAG AA (4.5:1) — **reuse the contrast helpers in `lib/uiTheme.ts`**; adjust
   lightness until it passes. Manual hex entry stays in the admin UI.
8. **Freeze branding in each saved quote:** when a configuration is saved (`api/configurations/route.ts`), store a
   `brandingSnapshot` (name, contact lines, colours, logo asset id + its sha) and the organization id. `quoteForToken.ts`
   uses the snapshot when present (the logo by the snapshotted asset id; keep old logo assets: never delete an asset
   referenced by a snapshot), else the current branding. A rebrand never changes an old PDF.
9. **Leftovers to theme you own:** `app/configuration/[token]/page.tsx` still uses the fixed orange → use the brand/theme accent.
