## Step 2 — live adaptation
- `quality.ts` (pure, unit-tested): a frame-time governor with hysteresis. Inputs: rolling frame times. Levels, lowered in
  this order: (1) environment reflections off, (2) shadow map size down (2048 → 1024 → 512), (3) far detail off (see step 3),
  (4) screen resolution (DPR) down last, to a floor of 1. Raise back one level at a time when frames are fast again for a
  sustained period. Named constants: target ms, slow/fast thresholds, sample window, cooldown.
- Frames are on demand (`frameloop="demand"`): only sample frames that were actually rendered during interaction; an idle
  canvas must not count as fast or slow. Never change quality while a quote render runs (`renders.tsx` has its own pass).
- `QualityToggle.tsx`: "Calitate: Auto / Ridicată" (Ridicată = the device tier's settings, no adaptation). Small, unobtrusive,
  works at 375 px, per-browser flag in localStorage (try/catch). Place it so it does not cover the view toolbar, the undo/redo
  buttons (bottom-left, above the "Control 3D" legend on desktop; bottom-left above the view bar on phones) or the admin bar.
